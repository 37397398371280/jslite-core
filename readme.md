# jslite-core (`v1.0.1`)

A zero-dependency JavaScript lite utility package engineered to parse and execute across **ECMAScript 3 (ES3)** engines while exposing ergonomic helpers from **ES5 through ES2026**.

## Modules Included
- `lite.cjs.js`: Universal UMD/CommonJS/Browser-global ES3-compatible core.
- `lite.esm.mjs`: ES module wrapper with named and default exports.
- `index.d.ts`: TypeScript definitions.
- `package.json`: Package manifest with `main`, `module`, `types`, and `exports`.
