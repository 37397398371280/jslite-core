jslite-core (v1.1.1) Documentation

jslite-core is a zero-dependency JavaScript lite utility package written in ES3-safe syntax with runtime feature detection and graceful fallbacks spanning ECMAScript 3 (ES3) through ECMAScript 2026 (ES2026).

Modules & Entry Points

  • jslite-core.cjs.js: Universal UMD/CommonJS/Browser-global (lite) core written in ES3-parseable syntax.
  • jslite-core.esm.mjs: ES module wrapper exporting lite as default alongside named exports for every utility.
  • index.d.ts: TypeScript declarations covering all top-level helpers and sub-APIs (era, setOps, query, storage, dom, date, encoding).
  • package.json: Package manifest with main, module, types, exports, repository, and license (GPL-3.0).
  • readme.md & LICENSE: Package overview and GNU General Public License v3.0.

1. Era & Capability Detection (lite.era)

var report = lite.era.detect();
// report.highest -> "ES3" .. "ES2026"
// report.capabilities -> boolean flags for es3..es2026

lite.era.isAtLeast("ES2022"); // => true or false

2. Type & Value Guards

Function Summary
typeOf(val) Returns "null", "undefined", "array", "date", "regexp", "map", "set", "weakmap", "weakset", "promise", "error", or typeof val.
isNil, isObj, isPlainObj, isFn, isArr, isNum, isStr, isBool, isEmpty Type and emptiness guards (isNum rejects NaN and Infinity; isEmpty supports strings, arrays, objects, Map, and Set).

4. Objects, Deep Paths, Circular Safety & Equality

clone(val, deep) and equal(a, b) track visited object and array references so circular references do not cause infinite recursion. 

var node = { name: "root" };
node.self = node;

var cloned = lite.clone(node, true);
lite.equal(node, cloned); // => true

var state = {};
lite.set(state, "items[0].title", "Hello");
lite.get(state, "items[0].title", ""); // => "Hello"
lite.pick({ a: 1, b: 2, c: 3 }, ["a", "c"]);
lite.omit({ a: 1, b: 2, c: 3 }, ["b"]);
lite.merge({ a: { x: 1 } }, { a: { y: 2 } });

6. Math, Function Wrappers, Timing, Async & Storage

Notice: Top-level await in the snippet below is valid only inside ES module contexts (such as <script type="module"> or .mjs files). In classic <script> tags, CommonJS, or legacy runtimes, place await inside an async function or use .then() / callbacks. 

lite.clamp(120, 0, 100);
lite.sumPrecise([0.1, 0.2, 0.3]);
lite.roundTo(3.14159, 2);
lite.randomInt(1, 6);

var onceFn = lite.once(function () { return lite.uid("id"); });
var memoFn = lite.memoize(function (x) { return x * 2; });
var fn = lite.pipe(function (x) { return x + 1; }, function (x) { return x * 3; });
var composed = lite.compose(function (x) { return x * 3; }, function (x) { return x + 1; });
var debounced = lite.debounce(function () {}, 200);
var throttled = lite.throttle(function () {}, 200);

await lite.sleep(50);
await lite.retry(function () { return "ok"; }, { retries: 3, delay: 100, backoff: 2 });
var deferred = lite.withResolvers();

lite.storage.set("prefs", { theme: "dark" });
lite.storage.get("prefs", {});
lite.storage.remove("prefs");
